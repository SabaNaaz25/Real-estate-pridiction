# Real Estate Price Prediction

## Overview
This project predicts real estate prices in Lakhs using key features like area, bedrooms, age, location score, and distance from the city. The prediction is based on a Linear Regression machine learning model.

## Folder Structure
- `main.py`: The main Python script that generates the synthetic dataset, trains the model, and outputs accuracy.
- `dataset.csv`: A sample dataset file containing formatted numerical data.
- `requirements.txt`: List of Python libraries required.
- `README.md`: Project overview and instructions.
